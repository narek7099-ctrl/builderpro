# Material category images

Drop a photo here named after the category, lowercased:

    assets/materials/<category>.jpg

Then add the name to SP.CATIMG in portal/supply-catalog.js. Only listed
names are requested, so partial sets are fine — anything missing keeps its
drawn icon.

- **JPG, 600x600, square.** Cards crop to fill, so keep the subject centred.
- A clean product shot on a plain light background works best; the card
  behind it is near-white.
- One photo covers every material in that category, so pick something
  representative rather than one specific SKU.
