System Check

Tests every BuilderPro backend piece from your browser. Green = working. Red shows the error so we can fix it.
The money test (manual — the only part a page can't do)
Run this once with your own phone as the customer:
1. Portal → Finances → + New estimate → yourself → $1 → send → tap Accept on the link.
  ✅ Opportunity moves to "Approved — Deposit Due" + you get a notification.
2. + New invoice → Deposit → $1 → send → pay it with a real card.
  ✅ Opportunity → Won, notification arrives, and the job appears in Active Projects on its own.
3. Active Projects → Mark done ✓ on that job.
  ✅ "Send the final invoice" notification arrives.
4. + New invoice → Final balance → $1 → send → pay.
  ✅ Contact gets paid-in-full tag, review text arrives ~1 day later (check the contact's tags immediately).
5. Check the contact in GHL after each step — the tag trail (deposit-sent → gone, final-sent → gone, paid-in-full) tells you every wire fired.
